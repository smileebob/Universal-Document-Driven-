## 四、配置生效 ≤5s

既有阶段证据引用：meta-service 配置发布→L1/L2 缓存失效→runtime 回源生效的端到端探针，

## 五、首屏 ≤3s：前端产物体积核对

`doc-web` 生产构建产物（dist，未压缩口径）：

| 产物 | 体积 |
| --- | --- |
| dist 总计（42 文件） | 2.65 MB |
| vendor-g6（G6 图表） | 1384 KB |
| vendor-antd | 1007 KB |
| vendor-vue | 105 KB |
| vendor-axios | 47 KB |
| index（入口） | 18 KB |
| 业务路由 chunk（按需） | 9~12 KB/页 |

估算：入口关键资源 = index(18KB) + vendor-vue(105KB) + vendor-antd(1007KB)，
gzip 压缩比按 0.3 估算约 340KB，加路由按需 chunk <20KB；
即使按最保守的 1MB/s 弱网估算首屏资源到达 <1s，加上 HTML/解析渲染，
**首屏 ≤3s 达标**（阶段一/二 E2E 浏览器验证亦未出现首屏超时）。
G6（1384KB）仅运营监控页按需加载，不计入首屏。
